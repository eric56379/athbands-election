Athletic Bands Election Result Processor

Directions:

  1. Log into Campus Groups and access the election under "Surveys & Forms".
  2. Click on the election URL to view all the results. Make sure that all invalid results are stripped from the election.
  3. A button that says "Generate Report" is near the top of the page. Before clicking on the button, there is a checkbox to the left. Click on this checkbox.
  4. Click on "Select all XX Submissions" to select all the results.
  5. Now, click "Generate Report", which will download a CSV file.
  6. Upload the CSV file to this website.
